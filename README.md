# Uday Mali - Personal Portfolio Website

## Project Overview
A responsive personal portfolio website built using HTML and CSS to showcase my education, technical skills, DevOps projects, achievements, and contact information.

## Objective
To deploy a static website for free using GitHub Pages.

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub Pages

## Website Sections
- Home
- About Me
- Technical Skills
- Projects
- Certifications & Achievements
- Contact

## Features
- Responsive layout
- Custom dark theme
- Navigation links
- Project and skills sections
- Contact and social profile links

## Run Locally
1. Clone this repository.
2. Open `index.html` in a browser.
3. Alternatively, use the VS Code Live Server extension.

## GitHub Pages Deployment
1. Push the project to GitHub.
2. Open repository Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/(root)`.
6. Click Save.
7. Open the published website URL.
